# 稳定性验收清单（v0.8.6）

此清单用于 v0.8.6 试用验收。使用独立测试账号、测试工作区和测试设备；不要在生产网络设备上执行示例命令。

本机调试时先创建空的临时目录，并在启动进程前设置 `MOQI_TEST_USER_DATA` 指向该目录。此变量只在明确设置时启用，连默认工作区也会改到该目录；不设置时仍沿用现有用户资料。仅修改 `APPDATA` 不足以隔离墨启的资料目录。

## 已自动检查

CI 在一次性 PostgreSQL 数据库中运行 `npm run smoke:server-qa` 与 `npm run smoke:collab`，覆盖个人笔记不对其他成员可见、受限团队文件夹、只读用户的协作编辑不广播、共享会话可见性与使用/编辑权限，以及两个协作客户端的基本同步。桌面端与服务器端执行类型检查，桌面端构建。

## 必须手动验证

- [ ] 分别使用自己的 ChatGPT、Gemini、豆包、Codex 账号登录；切换、刷新、关闭并重开应用后仍能保持预期状态。
- [ ] 在不同 Windows/macOS 系统用户下启动应用，确认网页登录和笔记数据不会跨系统用户混用；清除某一服务登录后检查其他服务，特别注意 ChatGPT 与 Codex 共用登录。
- [ ] 笔记与网页 AI 并排、拖动分屏、调整窗口大小；最大化笔记时网页不可遮挡，恢复后网页应回到右侧。
- [ ] 打开设置、右键菜单等遮挡层，检查网页不会盖住弹窗；退出登录后应显示登录页。若网站拒绝嵌入或弹出独立登录窗口，记录服务名、网址与提示。
- [ ] 两个不同账号同时编辑同一团队笔记，撤销、保存、关闭重开后内容一致；只读成员不能编辑，个人笔记不出现在其他成员资料树。
- [ ] 会话按“仅本人/全团队/指定成员”切换共享；使用权限可连接但不可改设置，编辑权限可修改；密码和私钥不应同步。
- [ ] 使用测试设备断开 SSH/Telnet 后重连；确认命令不重复下发、执行记录和输出日志完整。
- [ ] 在测试设备上运行工作流，检查状态与日志；运行中取消后确认不再下发后续命令，历史记录显示“已取消”。
- [ ] 创建多工作表、切换和编辑单元格，保存、关闭、重开后内容与格式仍在。
- [ ] Windows 与 macOS 新安装均可启动；从 v0.8.5 升级后旧笔记、工作区和登录配置仍在；分别检查安装包签名/系统安全提示及自动更新。

## 打包检查

`npm run dist:win` 在 Windows 检查 NSIS 与便携包；构建后运行 `scripts/serial-package-smoke.cjs` 检查串口组件。macOS 包必须在 macOS runner 上以 `npm run dist:mac` 构建并检查 Intel/Apple Silicon 的 DMG、ZIP 与 `latest-mac.yml`。无 macOS runner、真实服务账号或测试设备时，上述对应验收项只能标为未验证，不能写成通过。
